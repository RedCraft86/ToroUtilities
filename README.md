## Installation / Usage
1) Switch to the branch you want to download. Main branch is always the latest version.
2) Either click on the "Code" dropdown on the top right and download 
<br> **or**
<br> Clone said branch via an app like GitHub Desktop.
3) Compile and use the plugin in your C++ project.
4) **\[Optional]** If you want this for a BP only project (not recommended), you must compile the plugin in a C++ project first, then click on "Package" on the plugin in the plugins window.
